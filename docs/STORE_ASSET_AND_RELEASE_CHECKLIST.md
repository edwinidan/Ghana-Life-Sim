# Store Asset and Release Checklist

## Complete locally

- [x] Production app name and identifiers.
- [x] Version `1.0.0+2`.
- [x] Production launcher/app icon sets present.
- [x] Android target SDK 36 and arm64 support.
- [x] Signed Android release APK and AAB build.
- [x] iOS simulator and unsigned release-mode builds.
- [x] No ads, purchases, analytics, accounts, or dangerous permissions.
- [x] Offline first-launch architecture.
- [x] Privacy/SDK inventory.
- [x] Save migration, backup, recovery, and duplicate-commit tests.

## Owner/store-console work

- [ ] Publish and supply privacy-policy URL.
- [ ] Supply support URL and support email.
- [ ] Google Play feature graphic.
- [ ] Android phone screenshots.
- [ ] Tablet screenshots if tablet distribution remains enabled.
- [ ] iPhone screenshots.
- [ ] iPad screenshots because iPad distribution is enabled.
- [ ] Google short/full descriptions.
- [ ] Apple subtitle, keywords, promotional text, and review notes.
- [ ] Content/age-rating questionnaires.
- [ ] Google Data safety and ads declarations.
- [ ] Apple App Privacy and export-compliance answers.
- [ ] Play App Signing and closed testing.
- [ ] iOS distribution signing, archive, and TestFlight.
- [ ] TalkBack, VoiceOver, physical-device, and low-memory QA.
- [ ] Pre-launch report and beta feedback review.
